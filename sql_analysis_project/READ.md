# SQL Data Analyst Portfolio Project

## 📌 Project Overview

This project focuses on using SQL to explore sales data and perform different types of analysis to understand business performance, customer behaviour, and product sales.

I completed this project by following the SQL Data Analyst Portfolio Project tutorial by **[Data with Baraa](https://www.youtube.com/watch?v=2jGhQpbzHes)**. Through this hands-on practice, I strengthened my SQL skills and learned how different analytical techniques can be applied to real-world business scenarios.

## 🎯 Project Objectives

- Practise writing SQL queries to analyse sales data.
- Understand how SQL can be used to answer business questions.
- Learn different analytical techniques for evaluating sales, customers, and products.
- Improve my ability to structure queries using Common Table Expressions (CTEs) and other SQL features.
- Build a foundation for conducting independent data analysis projects.

## 🛠️ Tools & Technologies

- **SQL Server** — writing and executing SQL queries.
- **SQL Server Management Studio (SSMS)** — querying and exploring the database.

## 📊 Analysis Performed

### 1. Change Over Time Analysis
Analyse sales trends over different periods to identify changes in business performance.

### 2. Cumulative Analysis
Calculate running totals and cumulative metrics to understand how performance develops over time.

### 3. Performance Analysis
Evaluate product performance and compare results against relevant benchmarks.

### 4. Part-to-Whole Analysis
Examine how individual product categories or segments contribute to overall sales.

### 5. Data Segmentation
Group customers and products into meaningful segments to explore differences in purchasing behaviour and sales performance.

### 6. Customer Report
Combine customer-related metrics into a structured report to support customer analysis and business decision-making.

### 7. Product Report
Summarise product-level metrics to evaluate sales performance and identify useful patterns across products.

## 💡 Key Learnings

Through this project, I gained practical experience with:

- Common Table Expressions (CTEs) for breaking complex queries into smaller, more readable steps.
- Aggregate functions and grouping for summarising business data.
- Window functions for calculating cumulative metrics and supporting analytical comparisons.
- Date-based analysis for identifying trends over time.
- SQL techniques for comparing performance and segmenting data.
- Combining multiple analytical techniques to create customer and product reports.

One of my biggest takeaways was becoming more comfortable with CTEs. I learned how they can improve query readability and make multi-step analysis easier to understand and maintain.

## 🚀 Next Steps

I plan to build on these skills through independent SQL projects by developing my own business questions, writing queries to investigate them, and interpreting the results to generate actionable insights.
